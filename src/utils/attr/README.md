# getAttr  

**<code>getAttr(attr: string[], preview?: boolean, entryId?: string, fieldId?: string, offset?: string): string</code>**  

Convert attributes to string and optional Contentful preview attributes.

## Parameters  
- **`attr`** <code>string[]</code> required  
- **`preview`** <code>boolean</code> optional  
Default: `false`  
- **`entryId`** <code>string</code> optional  
- **`fieldId`** <code>string</code> optional  
- **`offset`** <code>string</code> optional  
Default: `false`

## Returns  

<code>string</code>
